## 重复生成

```bash
cd /workspace/work
bash scripts/check-ppt-environment.sh
source scripts/ppt-runtime.sh
"$RUNTIME_NODE" scripts/rebuild-market-research.mjs
```

每次生成独立的`.local/market-research/run-*/`目录，包含候选文件、最终PPTX、4张PNG预览和验证回执。生成脚本执行原生表格边框、图表排序与标签处理、上游便携性处理、官方finalizer、字体检查、3个内嵌数据工作簿创建及最终文件重新导入渲染。完成布局修改后执行：

```bash
"$RUNTIME_PYTHON" "$PRESENTATIONS_SKILL_DIR/container_tools/slides_test.py" /absolute/path/final.pptx
```

必须确认日志明确出现`Test passed. No overflow detected.`且没有`ERROR:`。生成器输出到临时目录，审阅后再将最终文件复制到`exports/`。
